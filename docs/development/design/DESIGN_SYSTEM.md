# Дизайн-система «Факт»

**Единственный файл-источник:** [`src/assets/ui.css`](../../../src/assets/ui.css).
Токены и примитивы правятся только там. Локальных «почти таких же» стилей
в компонентах быть не должно — если примитива не хватает, он добавляется в `ui.css`.

**Продуктовые ограничения:** [ТЗ_Фронтенд.md](../TZ/import/ТЗ_Фронтенд.md), разделы 3, 5.3, 9, 10.1.

Система нейтральная: серая шкала (zinc) плюс один сдержанный акцент. Фирменного
визуального языка у интерфейса нет — он не должен спорить с данными. Всё, что
ниже, выведено не из знака, а из работы: инструмент экономиста на восемь часов
в день, и главное на экране — цифры.

Стек: Tailwind CSS v4, CSS-first. Токены объявлены через `@theme static`,
поэтому доступны и как утилиты (`bg-ui-surface`, `text-ui-fg-muted`,
`border-ui-line`, `rounded-ui-lg`, `shadow-ui-sm`, `text-ui-table`,
`font-ui-sans`), и как переменные (`var(--color-ui-surface)`).

Утилиты порождают только именованные группы Tailwind: `--color-*`, `--font-*`,
`--text-*`, `--tracking-*`, `--radius-*`, `--shadow-*`, `--ease-*`, `--animate-*`.
Токены вида `--ui-row-h`, `--ui-border`, `--ui-gap`, `--ui-measure` утилит **не
дают** — они существуют только как `var()` и применяются внутри `ui.css`.

## 0. Пять правил

| Правило | Что это значит на практике |
|---|---|
| **Тон, а не вес** | Плоскости различаются тоном плоскости, волосяной границей 1px и мягкой короткой тенью. Толстая рамка конструкцию больше не несёт: карточка — это `1px` + `--radius-ui-lg` + `--shadow-ui-sm`. |
| **Акцент — редкий** | Индиго применяется к главному действию, активной вкладке, кольцу фокуса, стрелке сортировки, ховеру строки, номеру шага, правленой ячейке книги. Не фон блока, не декор под заголовком и не признак каждой строки в колонке. |
| **Статус — не акцент** | Успех / внимание / отказ живут на своих токенах (`--color-ui-success` / `--color-ui-warn` / `--color-ui-danger`) и с акцентом не смешиваются: «главное действие» и «всё сошлось» — разные сообщения. |
| **Иерархия — три ступени** | Заголовок экрана 26px → заголовок блока 15px → ровный тихий фон (14/13/12/11px). Четвёртой ступени нет: подписи, счётчики, техподписи и предупреждения весят одинаково тихо, а разницу несут положение и цвет текста, а не размер. |
| **Тихий капс** | UPPERCASE остался у `.ui-kicker`: 11px, разрядка `0.08em`. Кнопки, шапки таблиц, плашки, ярлыки, вкладки, счётчики — обычный регистр. Разрядки 0.34em в системе нет. |

Шестое, отдельное: **состояние никогда не передаётся одним только цветом.**
Рядом всегда стоит слово, а у индикатора сервиса — ещё и форма заливки
(критерий приёмки 11.7).

## 2. Тёмная тема

Тёмная тема — не отдельная палитра, а **другие значения тех же ролей**.
Компонент, написанный на токенах, переключается сам; компонент с хардкодом HEX
в тёмной теме ломается — отсюда все запреты §7.

### Как устроено

В `ui.css` три блока объявлений, и порядок между ними обязателен:

```css
@theme static { /* 1. светлая тема — полный набор ролей */ }

@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) { /* 2. системная тёмная */ }
}

:root[data-theme="dark"] { /* 3. явный выбор пользователя */ }
```

1. `@theme static` объявляет **весь** набор токенов. `static` нужен, чтобы
   переменные попадали в `:root` независимо от того, использована ли утилита
   хоть в одном компоненте: иначе в тёмной теме переопределять было бы нечего.
2. Системная тёмная применяется только при `:root:not([data-theme="light"])` —
   пользователь, выбравший светлую руками, не должен получать тёмную от системы.
3. `:root[data-theme="dark"]` идёт последним и по порядку каскада побеждает
   в обе стороны: тёмная включается на светлой системе, светлая (отсутствием
   атрибута плюс `[data-theme="light"]`) — на тёмной.

Переопределяются только те роли, у которых меняется значение: акцент, текст,
инверсия, плоскости, линии, статусы, фокус и **тени** (на тёмной плоскости
серая тень не видна — там она чёрная и плотнее). Размеры, шрифты, радиусы,
плотность и движение общие для обеих тем.

Базовый слой синхронно ведёт `color-scheme` — от него зависят системные
элементы: полосы прокрутки, нативные контролы, `::selection`:

```css
html { color-scheme: light; }
@media (prefers-color-scheme: dark) { html:not([data-theme="light"]) { color-scheme: dark; } }
html[data-theme="dark"]  { color-scheme: dark; }
html[data-theme="light"] { color-scheme: light; }
```

### Переключатель

- [`src/composables/useTheme.ts`](../../../src/composables/useTheme.ts) — три
  режима `system` / `light` / `dark`, обход по клику `система → светлая →
  тёмная → система`. Режим `system` атрибут **снимает**, остальные ставят
  `data-theme` на `<html>`. Хранится в `localStorage` под ключом `ui-theme`;
  запрет хранилища не считается ошибкой — тема просто живёт до конца сессии.
- [`src/components/layout/ThemeToggle.vue`](../../../src/components/layout/ThemeToggle.vue)
  — кнопка `.ui-theme-toggle` в правой зоне шапки, подпись состояния приходит
  из `THEME_LABEL`.
- В `index.html` стоит короткий скрипт, ставящий `data-theme` **до первой
  отрисовки**: иначе тёмный интерфейс моргает белым, пока грузится приложение.
  Логика в скрипте дублирует `useTheme.ts` — правя одно, правьте второе.

### Как добавить новый токен

1. Объявить роль в `@theme static` со **светлым** значением.
2. Если это цвет или тень — добавить её в **оба** тёмных блока: и в
   `@media (prefers-color-scheme: dark) :root:not([data-theme="light"])`,
   и в `:root[data-theme="dark"]`. Блоки дублируют друг друга дословно;
   расхождение между ними — дефект, а не оптимизация.
3. Проверить примитив в трёх режимах переключателя и в обеих системных
   настройках. «Проверил в светлой» — незакрытая задача.

**Нельзя объявлять цвет только внутри media-блока.** Роль, у которой нет
значения в `@theme static`, в светлой теме не существует вовсе: утилита
Tailwind не сгенерируется, `var()` уйдёт в пустоту, и компонент останется без
цвета ровно там, где его смотрит заказчик. Media-блок только **переопределяет**
то, что уже объявлено.

Единственная сознательная константа вне ролей — завеса диалога
(`rgb(9 9 11 / 0.5)` плюс `blur(2px)`): затемнение под окном должно быть
тёмным в обеих темах, поэтому оно не переворачивается. Других исключений нет.

## 3. Типографика, плотность, конструкция

Семейства (только системные стеки, ТЗ 10.1 — внешних шрифтов не подгружается):

- `--font-ui-sans` → `system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, "Liberation Sans", sans-serif` — всё тело интерфейса, включая шапки таблиц, ярлыки, плашки и вкладки;
- `--font-ui-num` — **тот же санс**: «моно-цифры» это `tabular-nums`, а не моноширинный шрифт. Колонка складывается глазом, а гарнитура интерфейса не рвётся;
- `--font-ui-mono` → `ui-monospace, "Cascadia Mono", "Consolas", "Liberation Mono", monospace` — **только** ответ сервиса, формула, `<code>`. Суммы моноширинным шрифтом не набираются никогда.

Три ступени, не шесть. Всё в ступени 3 — «ровный тихий фон»: подпись, счётчик,
предупреждение и техподпись различаются цветом текста и положением, а не
размером. Прибавлять четвёртую ступень «чтобы это тоже заметили» нельзя.

Разрядки: `--tracking-ui-kicker` (`0.08em`), `--tracking-ui-cap` (`0`),
`--tracking-ui-tight` (`-0.02em`).

Мера абзаца — `--ui-measure` (`68ch`), уже стоит на `p` в базовом слое.
Производные от неё: `--ui-notice-w` (`мера + 38px`) и `--ui-notice-w-tight`
(`мера + 30px`) — ширина блока-сообщения, то есть мера плюс его собственные
поля и рамка (§6.5).

### Плотность, границы, скругления, тени, движение

| Группа | Токены |
|---|---|
| Плотность | `--ui-control-h` 32px, `--ui-control-h-sm` 26px, `--ui-row-h` 30px, `--ui-head-h` 34px, `--ui-cell-x` 10px, `--ui-cell-y` 5px, `--ui-pad-card` 20px, `--ui-gap` 12px, `--ui-gap-lg` 20px, `--ui-gap-screen` 24px, `--ui-shell-w` 1600px |
| Границы | `--ui-border-hair` 1px (**всё, что разделяет**), `--ui-border` 2px (**только акцентная обводка**), `--ui-rule` 3px (линейка-сигнал слева у блока-сообщения, отбивка правленой ячейки, полоса ожидания), `--ui-rule-thin` 2px (активная вкладка, каретка загрузки), `--ui-underline` 1px (`.ui-rule-line`) |
| Скругления | `--radius-ui-none` 0, `--radius-ui-sm` 4px (плашка в таблице, мелкий контрол), `--radius-ui` 6px (кнопка, поле, вкладка), `--radius-ui-lg` 10px (карточка, панель, диалог, обёртка таблицы), `--radius-ui-full` 999px (пилюля, чип, точка индикатора) |
| Тени | `--shadow-ui-sm` (карточка, кнопка, поле), `--shadow-ui`, `--shadow-ui-md`, `--shadow-ui-lg` (диалог, панель выбора периода, пузырь подсказки) |
| Движение | `--ui-dur-fast` 100ms, `--ui-dur` 160ms, `--ease-ui`, `--animate-ui-sweep` (бегущая каретка ожидания) |

**Где какая граница.** По умолчанию — `--ui-border-hair` (1px). `--ui-border`
(2px) применяется ровно в четырёх ролях и нигде больше: кольцо `:focus-visible`
(включая собственные обводки фокуса у `.ui-period-toggle`, `summary` в
`.ui-details` и флажка `.ui-switch`), рамка точки индикатора сервиса, контур
выбранной ячейки книги (`.ui-grid-cell[aria-selected="true"]`) и обводка
редактируемой ячейки (`.ui-grid-input`). Толщиной рамки конструкция больше
не строится — её строят тон, скругление и тень.

**Тени короткие.** Плоскость не «взлетает»: `--shadow-ui-sm` — это 1–2px
смещения при 5–6 % непрозрачности. `--shadow-ui-lg` оставлена тому, что лежит
поверх экрана: диалог, панель выбора периода, пузырь подсказки.

**Воздух — только между блоками.** `--ui-gap-screen` (24px) разводит блоки
экрана, `--ui-gap` (12px) — содержимое внутри блока. Плотность **внутри таблицы
не меняется**: строка 30px, ячейка 5/10px, `.ui-table-dense` 26px. Цифры обязаны
помещаться на экран — это ровно то, ради чего экономист открывает экран.

**Движение сдержанное** и отключается системной настройкой: в базовом слое
стоит `@media (prefers-reduced-motion: reduce)`, обнуляющий длительности.

## 4. Правила таблиц сумм (обязательные)

Из ТЗ 5.3.2 и ТЗ 9 — не предмет вкуса.

1. **Все суммы:** `tabular-nums`, выравнивание вправо, класс `.ui-num`.
2. **Формат:** `15 124 465,77` — неразрывный пробел в разрядах, запятая,
   всегда две цифры после запятой.
3. **Ноль пишется `0,00`.** Прочерка вместо нуля не существует.
4. **Пустая ячейка означает «нет данных»** и остаётся пустой: `.ui-table
   td.ui-num:empty` получает еле заметную штриховку `--color-ui-wash`, чтобы
   её нельзя было прочитать как ноль или как забытый рендер.
5. **Суммы приходят строками и через `parseFloat` не прогоняются** (ТЗ 5.3.1).
   Форматирование — работа со строкой, сравнение и сортировка — `decimal.js`.
6. **Шапка липкая**, **колонка номера заказа липкая слева** (`.ui-col-key`),
   **строка итогов липкая снизу** (`tfoot`) — итоги не уходят под прокрутку.
7. **Прокручивается таблица, а не страница.** Обе прокрутки живут внутри
   `.ui-table-wrap`; задайте ей `max-block-size` от высоты окна.
8. **Колонки строятся по фактическому составу ключей `by_column`**, а не по
   захардкоженному `CC/CD/CE` (ТЗ 5.2, критерий 11.9).
9. **Термины — дословно из глоссария ТЗ 3:** «Себестоимость по 1С»,
   «Полная упр. себестоимость», «НЗП», «CC/CD/CE/CF», «Брак (28 сч)».
   Переименовывать «под красоту» запрещено: пользователь сверяет с ОСВ.
10. «В работе» и «участвует в распределении 26 сч» — **разные признаки**,
    оформляются разными плашками и никогда не сливаются в одну колонку.
11. Колонки разлинованы волосяной линией `--color-ui-line-soft`. Таблица
    тянется во всю рабочую ширину, и без разлиновки цифра отрывается от своего
    заголовка. Структурные границы (`.ui-col-key`, `.ui-col-split`, черта под
    шапкой и над итогами) идут `--color-ui-line-strong`: структурная граница
    обязана отличаться от разлиновки внутри блока.

### Правило веса: элемент задаёт умолчание, примитив несёт намерение

Правило вида `.ui-table tbody td` (0,1,2) **тяжелее**, чем примитив `.ui-num`
(0,1,0), и молча его перебивает. Однажды это уже стоило проекту дефекта:
шапка денежной колонки стояла вправо, а цифры под ней — влево, и колонка
переставала складываться в столбец.

Поэтому в системе:

- правило элемента объявляет свойство, **только если браузер ставит своё**
  (например, `text-align` у `th`, который по умолчанию центрируется; у `td`
  умолчание и так `start`, и лишняя декларация перебивала бы `.ui-num`);
- выравнивание денежной ячейки закреплено отдельным правилом
  `.ui-table td.ui-num` / `.ui-table th.ui-num` (0,2,1) — оно выигрывает
  в шапке, в теле и в итогах одинаково. Тем же приёмом закреплены
  `.ui-pct` и `.ui-micro` внутри таблицы.

Добавляя правило для `td` или `th`, проверьте, не перебивает ли оно примитив,
который на эту же ячейку ставится: `.ui-num`, `.ui-pct`, `.ui-micro`,
`.ui-col-key`, `.ui-col-split`.

## 5. Примитивы

### 5.1. Типографские

```html
<div class="ui-kicker">Шаг 1</div>       <!-- тихий капс 11px / 0.08em -->
<h1 class="ui-title">Состав расчёта</h1> <!-- ступень 1: 26px -->
<div class="ui-rule-accent"></div>       <!-- черта раздела: волосяная + акцентный засечек -->

<h2 class="ui-section">Состав заказов</h2>  <!-- ступень 2: 15px, обычный регистр -->
<p class="ui-hint">Первый запрос после простоя 1С может занять до полутора минут.</p>
<span class="ui-nodata">нет данных</span>
```

**`.ui-rule-accent` — черта раздела, а не полотно:** волосяная линия
`--color-ui-line` во всю ширину плюс акцентный засечек 44×3px в начале строки.
Документ делится, веса не прибавляется. Соседние примитивы:

- `.ui-rule-accent-thin` — акцентная полоса 2px во всю ширину (активная вкладка, полоса ожидания);
- `.ui-rule-line` — нейтральная черта 1px;
- `.ui-hatch` — штриховка 45° цветом `--color-ui-wash`, фактура «здесь данных нет».

Два вторичных текста не путать:

- **`.ui-hint` (14px, `fg-weak`)** — лид под заголовком экрана, пояснение под
  полем. Это текст, который читают.
- **`.ui-micro` (11px, `fg-muted`)** — техподпись: GUID, счётчик строк, ответ
  сервиса в одну строку. Это текст, в который заглядывают.

Ставить `.ui-micro` там, где нужен лид, нельзя: на рабочем расстоянии 11px
не читается, а подзаголовок экрана обязан читаться.

### 5.2. Карточка

```html
<section class="ui-card">…</section>                <!-- 1px + radius-lg + shadow-sm -->
<section class="ui-card ui-card-sheet">…</section>  <!-- рабочая плоскость sheet -->
<section class="ui-card ui-card-inverse ui-on-inverse">…</section> <!-- инверсия, сводка -->
<section class="ui-card ui-card-flush">             <!-- под таблицу: полей нет -->
  <div class="ui-table-wrap">…</div>
</section>
```

Карточку держат **плоскость, волосяная граница, скругление 10px и короткая
тень**. `.ui-card-flush` снимает поля и обрезает содержимое по радиусу — внутри
неё `.ui-table-wrap` теряет собственную рамку и скругление: обводка одна,
не две. Вертикальный ритм внутри карточки (12px) задаёт система, писать
отступы в компонентах не нужно.

`.ui-card-inverse` переворачивает плоскость (`--color-ui-inverse`) и сама
приглушает вложенные `.ui-kicker` и `.ui-hint`. `.ui-on-inverse` и
`.ui-on-accent` собственного оформления не имеют — это маркеры для потомков:
внутри них кольцо `:focus-visible` перекрашивается в `--color-ui-surface`,
иначе оно тонет в залитой плоскости.

### 5.3. Кнопка

```html
<button class="ui-btn ui-btn-primary">Рассчитать месяц</button>
<button class="ui-btn ui-btn-secondary">Посмотреть состав</button>
<button class="ui-btn ui-btn-danger">Сбросить переопределение</button>
<button class="ui-btn ui-btn-ghost ui-btn-sm">Копировать текст ошибки</button>

<button class="ui-btn ui-btn-primary" disabled>Рассчитать месяц</button>
<button class="ui-btn ui-btn-primary" data-loading>Идёт расчёт…</button>
```

| Вариант | Плоскость | Где |
|---|---|---|
| `ui-btn-primary` | акцент + `on-accent` + `shadow-ui-sm` | главное действие экрана |
| `ui-btn-secondary` | `surface` в волосяной рамке | альтернатива, навигация |
| `ui-btn-danger` | `danger` + `on-danger` | разрушающее действие, сброс |
| `ui-btn-ghost` | без рамки и плоскости, текст `fg` | второстепенное в плотных панелях |

Подпись кнопки — **13px обычным регистром, без разрядки**; высота
`--ui-control-h` (32px), у `.ui-btn-sm` — 26px.

Призрачная кнопка набирается **текстом в полную силу, а не приглушённым
цветом**: иначе на экране она неотличима от выключенной, а это разные вещи —
одно действие доступно, другое нет. Приглушён только `:disabled`.

Состояния закрыты все: `hover`, `focus-visible`, `active`, `:disabled` /
`[aria-disabled="true"]` (плоскость `surface-sunken`, текст `fg-faint`,
`cursor: not-allowed` — не «дымка» из прозрачности), `[data-loading]`
(клики блокируются, подпись остаётся читаемой, у основания идёт акцентная
каретка `--animate-ui-sweep`).

Для долгих операций вне кнопки — отдельная полоса `<div class="ui-progress"></div>`.
Расчёт идёт минуты (ТЗ 7.1): индикация обязана появиться с первой секунды.

### 5.4. Поле

```html
<label class="ui-label" for="period">Период</label>
<input id="period" class="ui-input" placeholder="июнь 2026, 2026-06, 06.2026">

<input class="ui-input ui-input-num" inputmode="decimal" value="5 639 903,92">

<input class="ui-input" aria-invalid="true" aria-describedby="period-err">
<span id="period-err" class="ui-input-error">
  <strong>Период не распознан</strong>
  Двузначный год не принимается. Форматы: 2026-06, 06.2026, июнь 2026.
</span>
```

Состояния: `hover`, `focus-visible` (граница `--color-ui-focus` плюс кольцо
`0 0 0 3px` из того же цвета на 22 %), `:disabled` / `[readonly]`,
`[aria-invalid="true"]` (граница `danger`, габарит держит `border-box` —
соседние контролы не сдвигаются), `[data-loading]`.

`select.ui-input` рисует свою стрелку двумя градиентами: знак наследует цвет
текста и потому одинаково читается в обеих темах, внешних ресурсов не грузится.
`.ui-input-error` — линейка `--ui-rule` слева, заголовок `<strong>`, объяснение,
ответ сервиса и действие: ошибка всегда сопровождается действием (ТЗ 8.2).

Разбор периода — обязанность бэкенда (ТЗ 5.3.3): фронт показывает текст сервера,
регулярных выражений не дублирует.

### 5.5. Плашка

```html
<span class="ui-badge ui-badge-neutral">В работе</span>
<span class="ui-badge ui-badge-warn">Номер заказа не определён</span>
<span class="ui-badge ui-badge-deny">Не сошлось</span>
<span class="ui-badge ui-badge-ok">Расчёт выполнен</span>
```

Форма — пилюля `--radius-ui-full`; признак несут цвет плоскости и **слово
внутри**. Внутри таблицы плашка автоматически переходит на `--radius-ui-sm`
и нулевые вертикальные поля: пилюля в строке 30px смотрится крупнее, чем есть.

### 5.6. Таблица

```html
<div class="ui-table-wrap" style="max-block-size: calc(100vh - 260px)">
  <table class="ui-table">
    <thead>
      <tr>
        <th class="ui-col-key" aria-sort="none">Заказ</th>
        <th>Наименование группы</th>
        <th class="ui-num">CC</th>
        <th class="ui-num">CD</th>
        <th class="ui-num">CE</th>
        <th class="ui-num ui-col-split">Брак (28 сч)</th>
        <th class="ui-num ui-col-split">Себестоимость по 1С</th>
        <th>В работе</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <th class="ui-col-key" scope="row">П3747</th>
        <td>П3747 (изделие, 2 шт_Заказчик)</td>
        <td class="ui-num">7 015 883,49</td>
        <td class="ui-num">1 151 502,95</td>
        <td class="ui-num">2 956 961,42</td>
        <td class="ui-num ui-col-split">0,00</td>
        <td class="ui-num ui-num-strong ui-col-split">11 124 347,86</td>
        <td><span class="ui-badge ui-badge-neutral">В работе</span></td>
      </tr>
    </tbody>
    <tfoot>
      <tr>
        <th class="ui-col-key" scope="row">Итого</th>
        <td></td>
        <td class="ui-num">…</td><td class="ui-num">…</td><td class="ui-num">…</td>
        <td class="ui-num ui-col-split">0,00</td>
        <td class="ui-num ui-col-split">15 124 465,77</td>
        <td></td>
      </tr>
    </tfoot>
  </table>
</div>
```

- `.ui-table-wrap` — плоскость `sheet`, волосяная рамка, скругление 10px и обе
  прокрутки. `max-block-size` задаётся в месте применения: прокручивается
  таблица, а не страница. Внутри `.ui-card-flush` рамка и скругление снимаются —
  их держит карточка.
- `.ui-col-key` — липкая слева колонка номера заказа, граница справа
  `line-strong`. Ставится на первую ячейку в `thead`, `tbody` и `tfoot`,
  иначе колонка «поедет».
- **Липкость включается только внутри `.ui-table-wrap`.** Вложенная таблица
  (расшифровка в раскрытой строке, список групп в «Подробностях») своей
  прокрутки не имеет — её шапка остаётся на месте и не прилипает к окну.
- `thead th` — липкая шапка на `surface-sunken`, 12px обычным регистром,
  цвет `fg-muted`, черта 1px `line-strong` у основания. `aria-sort` включает
  курсор, наведение (текст в полную силу) и акцентную стрелку `↑` / `↓`.
- `tfoot` — липкая строка итогов на `surface-sunken`, черта 1px `line-strong`
  сверху, всегда видна.
- Зебра и наведение уже внутри: `tr:nth-child(even)` → `sheet-alt`,
  `tr:hover` → `accent-soft`. Раскрытая расшифровка — `[data-expanded="true"]`,
  выбранная строка — `[aria-selected="true"]` (обе `accent-soft`), исключённая
  из расчёта — `[data-muted="true"]` (текст `fg-muted`, остаётся читаемым).
- `.ui-col-split` — граница между блоками колонок (CC/CD/CE | брак | CF | итоги).
- Плотность: `.ui-table-dense` (26px, 12px) и `.ui-table-comfy` (36px).
- Пустое состояние — `.ui-table-empty` с содержательным текстом
  («за июнь 2026 в 1С нет ни одной группы с оборотом»), а не «нет строк».
  Внутри него `.ui-notice-text` центрируется, а `.ui-notice-actions`
  выравнивается по центру.

### 5.7. Денежная ячейка и доли

```html
<td class="ui-num">11 124 347,86</td>                 <!-- сумма -->
<td class="ui-num ui-num-strong">15 124 465,77</td>   <!-- итог -->
<td class="ui-num">0,00</td>                          <!-- ноль это ноль -->
<td class="ui-num"></td>                              <!-- нет данных: пусто + штриховка -->
<td class="ui-pct">82,47 %</td>                       <!-- доля в распределении 26 сч -->
```

Табличные цифры включены и в базовом слое — для `.ui-num`, `[data-num]`,
всех ячеек `.ui-table`, полей с `inputmode="decimal"` / `"numeric"`,
`<output>` и `<time>`.

### 5.8. Вкладки

```html
<div class="ui-tabs" role="tablist">
  <button class="ui-tab" role="tab" aria-selected="true">
    Свод по заказам <span class="ui-tab-count">27</span>
  </button>
  <button class="ui-tab" role="tab" aria-selected="false">Распределение 26 сч</button>
  <button class="ui-tab" role="tab" aria-selected="false">Расшифровка</button>
  <button class="ui-tab" role="tab" aria-disabled="true" disabled>История</button>
</div>
```

Вкладка — 14px обычным регистром: это название представления, а не аббревиатура.
Активная отмечена акцентным текстом и полосой `--ui-rule-thin` поверх волосяной
линии контейнера. Счётчик `.ui-tab-count` показывает, сколько строк за вкладкой
стоит, и на активной переходит в `accent-soft` / `accent`.
Состояния: `hover`, `focus-visible`, `aria-selected`, `disabled` /
`[aria-disabled="true"]`.

## 6. Примитивы экранов

Второй слой системы: из него собраны каркас, предпросмотр, расчёт, результат,
несходимость и книга.

### 6.1. Каркас приложения

```html
<div class="ui-shell">
  <div class="ui-header-bar">
    <header class="ui-header">
      <a class="ui-brand">
        <span>
          <span class="ui-brand-name">Факт</span>
          <span class="ui-brand-sub">Управленческая таблица</span>
        </span>
      </a>
      <!-- поле периода, по центру -->
      <div class="ui-header-side">
        …индикатор сервиса, ссылка на историю…
        <button class="ui-theme-toggle">…</button>
      </div>
    </header>
  </div>

  <div class="ui-context">
    <span class="ui-kicker">Период: июнь 2026</span>  <!-- в строке контекста — обычным регистром -->
    <span class="ui-badge ui-badge-warn">Действует фильтр состава заказов</span>
  </div>

  <main class="ui-main">…</main>
</div>
```

`.ui-shell` — сетка `auto auto 1fr` на высоту окна: страница не прокручивается,
прокручиваются таблицы. `.ui-header-bar` кладёт плоскость `surface` и волосяную
черту во всю ширину окна, а рабочую ширину (`--ui-shell-w`, 1600px) держат
`.ui-header`, `.ui-context` и `.ui-main`.

Логотип — **текстовый**: `.ui-brand-name` («Факт») плюс `.ui-brand-sub`
(«Управленческая таблица»). Фирменной графики и знака в шапке нет.
`.ui-header` — сетка `1fr auto 1fr`: логотип прижат влево, поле периода строго
по центру, служебная зона вправо.

### 6.2. Экран

```html
<div class="ui-screen">
  <header class="ui-screen-head">
    <div>
      <div class="ui-kicker">Шаг 1</div>
      <h1 class="ui-title">Состав расчёта</h1>
      <p class="ui-hint">Что попадёт в расчёт за июнь 2026</p>
    </div>
    <div class="ui-screen-actions">
      <button class="ui-btn ui-btn-secondary">Обновить состав</button>
    </div>
  </header>
  <div class="ui-rule-accent"></div>
  …блоки экрана…
</div>
```

`.ui-screen` задаёт вертикальный ритм (`--ui-gap-screen`, 24px). Черта раздела
сразу после `.ui-screen-head` подтягивается к заголовку, а не висит в ритме
блоков.

`.ui-kicker` внутри `.ui-screen-head` — единственное место, где он остаётся
капсом. В строке контекста (`.ui-context`) и в шапке раскрытой строки
(`.ui-detail-head`) система сама переводит его в обычный регистр: там за ним
стоят данные (период, номер заказа), а не надзаголовок.

### 6.3. Индикатор сервиса

```html
<div class="ui-service">
  <span class="ui-status-dot" data-state="available"></span>
  <span class="ui-micro">Сервис доступен</span>
</div>
```

| `data-state` | Как выглядит |
|---|---|
| `available` | точка залита `success`, вокруг мягкое кольцо |
| `unavailable` | залита `danger` и **перечёркнута** светлой чертой |
| `checking` | штриховка 45° цветом `warn` в рамке `warn` |
| `unknown` | пустая точка в разомкнутой (пунктирной) рамке `fg-faint` |

Состояния различаются **и цветом, и формой заливки**: различие обязано читаться
в монохроме и при дальтонизме (критерий приёмки 11.7). Индикатор всегда
сопровождается словами — сама по себе точка ничего не сообщает.

### 6.4. Поле периода

```html
<div class="ui-period">
  <label class="ui-label" for="period-input">Период</label>

  <div class="ui-period-row">
    <div class="ui-period-control">
      <input id="period-input" class="ui-input" placeholder="июнь 2026">
      <button class="ui-period-toggle" aria-expanded="false" aria-label="Выбрать месяц">▾</button>
    </div>
    <button class="ui-btn ui-btn-primary">Показать состав</button>
  </div>

  <div class="ui-period-picker">
    <div class="ui-period-picker-head">
      <button class="ui-btn ui-btn-ghost ui-btn-sm">←</button>
      <span class="ui-num">2026</span>
      <button class="ui-btn ui-btn-ghost ui-btn-sm">→</button>
    </div>
    <div class="ui-period-picker-grid">
      <button class="ui-period-month">январь</button>
      …12 месяцев…
    </div>
    <p class="ui-hint">Выбор месяца заполняет поле — запрос отправляется кнопкой или Enter.</p>
  </div>

  <div class="ui-period-chips">
    <button class="ui-chip">Прошлый месяц</button>
    <button class="ui-chip">Текущий месяц</button>
  </div>
</div>
```

Кнопка `▾` живёт **внутри рамки поля**, панель выбора висит под полем
(`z-index: 30`, `--shadow-ui-lg`) и ничего не отправляет. Разбор периода —
обязанность бэкенда (ТЗ 5.3.3). Состояния закрыты у всех трёх контролов:
`hover`, `focus-visible`, `active`, `disabled`, `aria-expanded`.
Пояснения внутри `.ui-period` — техподпись 11px, а не лид экрана: система
сама уменьшает вложенный `.ui-hint`.

### 6.5. Блок-сообщение

Несущий примитив: предупреждения предпросмотра, панель ошибки, экран несходимости.

```html
<section class="ui-notice ui-notice-warn">
  <h2 class="ui-notice-title">Не определён номер заказа: 2 гр.</h2>
  <p class="ui-notice-text">Обороты этих групп не попадут ни в один заказ…</p>
  <div class="ui-notice-actions">
    <button class="ui-btn ui-btn-secondary ui-btn-sm">Обновить состав</button>
  </div>
</section>

<!-- однострочное пояснение без отбивки -->
<p class="ui-notice ui-notice-neutral ui-notice-tight">
  «В работе» и «участвует в распределении 26 сч» — разные признаки.
</p>
```

| Вариант | Линейка слева (`--ui-rule`, 3px) | Плоскость | Когда |
|---|---|---|---|
| `ui-notice-neutral` | `fg-faint` | `surface` | пояснение, фильтр состава, «из кэша» |
| `ui-notice-warn` | `warn` | `warn-soft` + `warn-line` | `unmatched`, оборот без группы, несохранённые правки |
| `ui-notice-deny` | `danger` | `danger-soft` + `danger-line` | ошибка запроса, отказ по сверке |

Сигнал несут линейка слева и тон плоскости, а не восклицательный знак: отказ
по сходимости — **штатное состояние** (ТЗ С4), поэтому ни иконок-предупреждений,
ни «Ошибка!».

#### Ширина: рамка идёт по тексту, а не по краю экрана

```css
inline-size: fit-content;
max-inline-size: min(100%, var(--ui-notice-w));   /* мера + 38px полей и рамки */
```

Растянутый на всю строку блок показывал рамку, у которой две трети пустые:
текст внутри держит меру в 68 знаков и обрывается заметно раньше правого края.

- `fit-content` вместо `auto` **отключает растяжку flex-элемента по поперечной
  оси**. Поэтому блок ведёт себя одинаково и в ритме экрана (`.ui-screen` —
  колоночный flex), и внутри карточки (блочный поток). Заменять на
  `width: auto` + `align-self: start` не нужно: тогда потолок перестанет
  работать в блочном контексте.
- Ширину задаёт самый широкий ребёнок: заголовок, строка кнопок или абзац
  на всю меру. У `.ui-notice-text` есть своя `max-inline-size: var(--ui-measure)`,
  и в расчёт максимального размера она входит уже обрезанной.
- `--ui-notice-w` считается в `ch` **от размера шрифта самого блока**, поэтому
  у `.ui-notice-tight` (13px) потолок свой — `--ui-notice-w-tight`, мера плюс
  его собственные, более узкие поля. Иначе два соседних блока-сообщения
  стояли бы по разным правым краям.

`.ui-notice-text` — основной абзац интерфейса, годится и внутри `.ui-card`,
и внутри диалога. `.ui-notice-actions` с пустым слотом схлопывается, чтобы не
оставлять дыру в вёрстке.

### 6.6. Счётчики

```html
<section class="ui-counters">
  <div class="ui-counter">
    <div class="ui-counter-label">Всего групп</div>
    <div class="ui-counter-value ui-num">27</div>
  </div>
  <div class="ui-counter ui-counter-wide">
    <div class="ui-counter-label">Суммарный оборот</div>
    <div class="ui-counter-value ui-num ui-num-strong">42 812 784,23</div>
  </div>
</section>
```

Сетка `auto-fit`, минимум 170px, шаг `--ui-gap`. Счётчик — плоскость `surface`
в волосяной рамке со скруглением 10px и `--shadow-ui-sm`, поля 12/14px:
он легче карточки экрана и не спорит с ней. `.ui-counter-wide` занимает две
колонки — денежной сумме нужна строка целиком. `.ui-counter-value` перебивает
размер `.ui-num` (21px), табличные цифры сохраняются. Подпись — 12px обычным
регистром, `--color-ui-fg-muted`.

### 6.7. Панель над таблицей

```html
<section class="ui-card ui-card-flush">
  <div class="ui-toolbar ui-toolbar-wrap">
    <label class="ui-field">
      <span class="ui-label">Заказ</span>
      <select class="ui-input">…</select>
    </label>
    <label class="ui-field ui-field-grow">
      <span class="ui-label">Поиск по статье затрат</span>
      <input class="ui-input" type="search">
    </label>
    <button class="ui-btn ui-btn-ghost ui-btn-sm">Сбросить фильтры</button>
  </div>

  <div class="ui-table-wrap">…</div>
</section>
```

`.ui-toolbar` — полоса `surface-soft` с волосяной чертой снизу: она не держит
плоскость, а только отбивает фильтры от данных. `.ui-toolbar-wrap` разрешает
перенос фильтров: их может быть много, и они переносятся, а не сжимаются
в нечитаемое. `.ui-field` — подпись над контролом, `.ui-field-grow` растягивает
поиск. Внутри `.ui-card-flush` рамку держит карточка.

### 6.8. Раскрываемый блок и диалог

```html
<details class="ui-details">
  <summary>Подробности</summary>
  <div class="ui-details-body">
    <dl class="ui-kv"><dt>Код ответа</dt><dd>502</dd></dl>
    <pre class="ui-pre">…ответ сервиса дословно…</pre>
  </div>
</details>

<dialog class="ui-dialog">
  <h2 class="ui-dialog-title">Запустить расчёт за июнь 2026</h2>
  <div class="ui-dialog-body"><p class="ui-notice-text">…</p></div>
  <div class="ui-dialog-actions">
    <button class="ui-btn ui-btn-primary">Запустить расчёт</button>
    <button class="ui-btn ui-btn-secondary">Отмена</button>
  </div>
</dialog>
```

Технические детали не попадают в основной текст (ТЗ 8.1). `summary` теряет
системный треугольник и получает `+` / `−` в квадратной рамке. Компонент —
[`src/components/ui/UiDialog.vue`](../../../src/components/ui/UiDialog.vue);
у `.ui-dialog` **не переопределяется `display`** — иначе нативное окно
перестанет закрываться. Завеса `::backdrop` — тёмная в обеих темах.

### 6.9. Подсказка к термину

```html
<span class="relative inline-flex items-center gap-1">
  Оборот
  <button class="ui-hint-mark" aria-expanded="false">?</button>
  <span class="ui-hint-bubble" role="tooltip">Оборот Дт по счетам расчёта (20.01 и 28).</span>
</span>
```

Живёт внутри `th`, в том числе липкого: пузырь снимает наследование шапки
(разрядку, `nowrap`, выравнивание) и всплывает над ячейками (`z-index: 40`).
Знак приглушён (`fg-muted`), при наведении и раскрытии переходит в акцент.
Раскрывается по клику, а не только по наведению.

### 6.10. Мелкие примитивы

| Класс | Что делает |
|---|---|
| `.ui-micro` | техническая подпись 11px, `fg-muted` |
| `.ui-measure` | ограничение меры абзаца `68ch` вне карточки |
| `.ui-kv` | `dl` определений в «Подробностях»: `dt` приглушён, `dd` значением |
| `.ui-pre` | ответ сервиса дословно, моноширинный **системный** стек на `surface-sunken`, высота до 260px с прокруткой |
| `.ui-steps` | нумерованные шаги «Что делать»: номер в акцентном кружке `accent-soft` |
| `.ui-nodata` | подпись «нет данных» 11px, `fg-faint` |
| `.ui-hatch` | штриховка «здесь данных нет» |

### 6.11. Раскрытие строки свода

```html
<tr data-expanded="true">…строка заказа…</tr>
<tr class="ui-row-detail">
  <td :colspan="…">
    <div class="ui-detail-head">
      <span class="ui-kicker">Расшифровка заказа П3747</span>
      <button class="ui-btn ui-btn-ghost ui-btn-sm">Открыть в расшифровке</button>
    </div>
    <table class="ui-table ui-table-dense">…</table>
  </td>
</tr>
```

Раскрытая строка — отдельная плоскость `surface-sunken`: зебра и наведение
на неё не действуют. Вложенная таблица получает собственную рамку со
скруглением `--radius-ui`, ширину по содержимому и **не липнет**: липкость
шапки, колонки заказа и строки итогов включается только внутри `.ui-table-wrap`.

### 6.12. Экран расчёта

```html
<div class="ui-calc-time ui-num">Идёт 4 мин 12 с</div>
<div class="ui-progress"></div>

<section class="ui-card ui-launch">
  <div>
    <h2 class="ui-section">Шаг 2. Расчёт месяца</h2>
    <p class="ui-notice-text">Расчёт занимает от нескольких секунд до 15 минут…</p>
  </div>
  <div class="ui-launch-action">
    <button class="ui-btn ui-btn-primary">Рассчитать месяц</button>
  </div>
</section>
```

`.ui-calc-time` — 32px табличными цифрами: показывается **честно прошедшее
время**, а не выдуманный процент. `.ui-launch` — предупреждение о длительности
слева, действие справа (ТЗ 7.1.2); собственный вертикальный ритм карточки
внутри него отключён.

### 6.13. Переключатель участия

```html
<label class="ui-switch">
  <input type="checkbox" checked>
  <span class="ui-badge ui-badge-neutral">Определено расчётом</span>
</label>
```

Флажок — квадрат `--radius-ui-sm`, во включённом состоянии акцентная плоскость
с белой галкой, нарисованной прямо в CSS (внешних ресурсов не подгружается,
ТЗ 10.1; на акцентной плоскости она одинакова в обеих темах). Рядом всегда
стоит плашка: расчётный признак и снятый вручную обязаны различаться словами,
а не только положением флажка (ТЗ С5).

### 6.14. Переключатель темы

```html
<button class="ui-theme-toggle" :title="THEME_LABEL[mode]" :aria-label="THEME_LABEL[mode]">
  <svg>…</svg>
</button>
```

Квадратная кнопка `--ui-control-h-sm` (26px) в правой зоне шапки: плоскость
`surface`, волосяная рамка, знак 14px. Состояние читается подписью
(`THEME_LABEL`), а не только формой знака. Три режима по кругу, см. §2.

### 6.15. Книга `.xlsx`

```html
<div class="ui-formula-bar">
  <span class="ui-formula-ref ui-num">D14</span>
  <span class="ui-formula-text">=СУММ(D2:D13)</span>
  <span class="ui-micro">Значение из файла: 15 124 465,77</span>
</div>

<div class="ui-table-wrap">
  <table class="ui-table ui-table-dense ui-grid">
    <thead>
      <tr>
        <th class="ui-col-key ui-grid-corner"></th>
        <th class="ui-grid-head">A</th>…
      </tr>
    </thead>
    <tbody>
      <tr>
        <th class="ui-col-key ui-grid-index" scope="row">14</th>
        <td class="ui-grid-cell ui-num" data-kind="formula" aria-selected="true">
          15 124 465,77 <span class="ui-cell-flag">ƒ</span>
        </td>
        <td class="ui-grid-cell" data-kind="text" data-edited="true">…</td>
        <td class="ui-grid-cell"><input class="ui-grid-input"></td>
      </tr>
    </tbody>
  </table>
</div>

<nav class="ui-sheet-tabs" role="tablist">
  <button class="ui-sheet-tab" aria-selected="true">Свод по заказам</button>
  <button class="ui-sheet-tab" disabled>Расшифровка</button>
</nav>
```

| Признак | Оформление |
|---|---|
| `data-kind="formula"` | знак `ƒ` акцентом (`.ui-cell-flag`); после правок книги — `≈` (значение могло устареть) |
| `data-kind="number"` | вправо, табличные цифры |
| `data-kind="empty"` | остаётся пустой **без штриховки**: в книге пустых ячеек по определению много |
| `data-edited="true"` | акцентная отбивка `--ui-rule` слева + промывка `accent-soft` + начертание |
| `aria-selected="true"` | акцентная вырубка по контуру (`outline: var(--ui-border)`, соседи не смещаются) |
| `.ui-sheet-tab[aria-selected]` | плоскость `surface` + акцентная черта сверху |
| `.ui-sheet-tab:disabled` | штриховка «лист не прочитан», курсор `not-allowed` |

Браузер формулы не пересчитывает (ТЗ 4.2.3) — формульная ячейка помечена
знаком, а не спрятана. Вкладки листов стоят **внизу**, как в Excel, и
прижимаются к сетке. Служебные колонка номеров (`.ui-grid-index`) и угол
(`.ui-grid-corner`) — плоскость `surface-sunken`, как строка итогов:
это не данные.

## 7. Запреты

Нарушение любого пункта — правка в ревью, а не предмет обсуждения.

| Запрещено | Почему |
|---|---|
| Хардкод HEX, `rgb()`, `oklch()` в компонентах и шаблонах | в тёмной теме такой цвет не переворачивается; все цвета — роли из `ui.css` |
| Локальные копии токенов и «почти такие же» стили в `<style>` компонента | единственный источник — `ui.css`; не хватает примитива — примитив добавляется туда |
| Объявление цвета или тени **только** внутри `@media (prefers-color-scheme: dark)` | в светлой теме роли не существует: утилита не сгенерируется, `var()` уйдёт в пустоту (§2) |
| Правка одного тёмного блока без второго | `:root:not([data-theme="light"])` и `:root[data-theme="dark"]` обязаны совпадать дословно |
| Сдача компонента, проверенного только в одной теме | обе темы — часть определения готовности |
| Набор экрана Tailwind-утилитами вместо примитивов (`bg-white border rounded-lg p-5` вместо `.ui-card`) | утилиты допустимы для раскладки, но роль и оформление несёт примитив |
| Цвета вне палитры: чужие акценты, бутстраповские синий/бирюзовый, второй акцент | акцент один, статусы три; больше в системе ролей нет |
| Акцент как признак строки, фон блока или декор под каждым заголовком | акцент — редкий: главное действие, активная вкладка, фокус, сортировка |
| Статусный цвет вместо акцента и наоборот («главная кнопка зелёная, раз всё сошлось») | это разные сообщения |
| Цвет как **единственный** носитель состояния | критерий приёмки 11.7: рядом обязано стоять слово, а у индикатора — ещё и форма заливки |
| Браузерная синяя обводка фокуса, `outline: none` без замены | фокус — `--color-ui-focus`, 2px, отступ 2px; на залитых плоскостях переворачивается через `.ui-on-inverse` / `.ui-on-accent` |
| Четвёртая ступень размера «чтобы это тоже заметили» | иерархия в три ступени; всё остальное — ровный тихий фон |
| `text-transform: uppercase` где-либо, кроме `.ui-kicker` | тихий капс работает, пока он один |
| `--ui-border` (2px) вне четырёх ролей из §3 | толщиной рамки конструкция не строится: тон, скругление, тень |
| Вторая обводка внутри уже обведённой плоскости | рамку держит внешняя карточка; `.ui-card-flush` снимает её у `.ui-table-wrap` |
| Тень крупнее `--shadow-ui-lg`, свечение, «стекло» под контентом | тени короткие: плоскость не «взлетает» |
| Изменение плотности внутри таблицы под конкретный экран | строка 30px неприкосновенна; допустимы только `.ui-table-dense` и `.ui-table-comfy` |
| Внешние шрифты, Google Fonts, любые CDN, внешние иконки и картинки | ТЗ 10.1: интернета в сети заказчика может не быть |
| Прочерк вместо нуля | ТЗ 5.3.2: ноль это `0,00`, пустая ячейка = «нет данных» |
| `parseFloat` / `Number` над денежной строкой | ТЗ 5.3.1: двоичная погрешность здесь — дефект |
| Пагинация в составе заказов | ТЗ С1: состав видно целиком |
| Кнопка «скачать всё равно» на экране несходимости | ТЗ С4 |
| Иконки-предупреждения и «Ошибка!» на штатном отказе по сверке | ТЗ С4: это штатный сценарий |
| Переименование терминов «под красоту» | ТЗ 3: пользователь сверяет с ОСВ |
| Смешение «в работе» и «участвует в распределении 26 сч» | ТЗ 3: это разные признаки |
| Рамка шире своего содержимого: блок на всю строку экрана вокруг текста в 68 знаков | §6.5: рамка идёт по тексту |
| Правило `td` / `th`, перебивающее примитив ячейки | §4: элемент задаёт умолчание, примитив несёт намерение |
